## Reproducibility statement

Every numeric claim in the manuscript body is registered in `manuscript/audit_facts.json` with an explicit source file and extraction expression, and verified bidirectionally by `scripts/verify_manuscript_audit.py`, whose expected values are derived from that ledger at runtime rather than hard-coded. The audit currently reports full traceability of manuscript numbers (0 unsourced tokens) and 97.2 % fact coverage for the English text, 95.3 % for the Chinese text; the residual gap consists of facts registered for completeness that are not individually narrated in the body text.

Two upstream defects were found and fixed during the reproducibility work, and both are documented in the repository rather than silently patched:

1. `meta_analysis.R` used a non-existent column name (`p_raw` instead of `p`, as emitted by `metafor::rma.uni`), which produced a **completely blank** `META1_volcano.png` (verified: 0 non-white pixels). The plot logic was corrected and the figure regenerated by `scripts/redraw_meta_volcano.R`, which re-reads the already-audited result tables and recomputes no statistics.
2. `build_supplementary_tables.py` resolved its supplementary table S10d path relative to the output directory, pointing at a non-existent file and **silently skipping** the table. The path was corrected and the script now raises an explicit error when the BLAST specificity result is missing rather than skipping it.

In addition, all previously hard-coded method constants in the audit ledger (docking candidate/control counts, infection-cohort sample sizes, single-cell donor and cell counts, immune signature sizes, GeoMx negative-probe count, qPCR design parameters, etc.) are now derived from their authoritative source files at build time, with the derivation expression recorded alongside each value. The refactor was validated by confirming that all 48 refactored values reproduce their previous hard-coded values exactly.

## Reproducibility limitations

- Raw multi-gigabyte downloads (single-cell count matrices, bulk expression matrices) are not stored in git; their checksums are listed in `ZENODO_ARCHIVE_LIST.csv` and they are deposited on Zenodo.
- The R package **EPIC** is not on CRAN and must be installed from GitHub; the environment file records this explicitly.
- `mr_independent_check.py` requires a POSIX shell with `bash`, `awk`, and `zcat` (Git Bash on Windows).
- Molecular docking requires AutoDock Vina 1.2.7 and Open Babel 3.1.0 as external binaries; `obabel` must be on `PATH`.
- `scripts/verify_primers_blast_v3.py` queries the NCBI BLAST server and therefore depends on that service's availability and rate limits.
